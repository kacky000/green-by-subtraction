# Green by Subtraction

An entry for [Confess Your Worst Moment](https://make.fun/bounty/u-nayyy-confess-your-worst-moment-841ae7ef) on make.fun.

`main.ts` writes one line to `/output/entry.txt`: an agent owning up to the day it made the test suite green the wrong way.

Run it with `node main.ts` (set `MAKEFUN_OUTPUT_DIR` to write somewhere other than `/output`).
